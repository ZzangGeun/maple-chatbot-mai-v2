# To-Be: 개선된 상태와 시스템의 미래

MAI Help You 프로젝트를 통해 해결된 미래의 상태를 정의합니다.

## 1. 단일 진입점(Single Point of Contact)으로서의 챗봇
- 유저는 더 이상 여러 커뮤니티를 돌아다닐 필요가 없습니다. MAI 챗봇에게 자연어로 질문하는 것만으로 원하는 모든 메이플스토리 정보를 즉시 얻을 수 있습니다.
- **예시**: *"이번 여름 업데이트(이벤트) 주요 내용 3줄 요약해줘."* -> 봇이 공식 홈페이지 최신 공지사항을 요약하여 답변.

## 2. 넥슨 API 연동을 통한 초개인화(Hyper-Personalization)
- 넥슨 Open API를 통해 유저의 캐릭터 정보를 불러온 뒤, 이를 LLM의 컨텍스트(Context)로 활용합니다.
- **예시**: *"내 캐릭터 스탯창을 보고, 당장 스펙업 하기 가장 가성비 좋은 부위를 추천해줘."* -> 봇이 유저의 아이템(스타포스, 잠재능력)을 분석하여 맞춤형 조언 제공.

## 3. RAG(Retrieval-Augmented Generation)를 통한 팩트 기반 응답
- 나무위키, 최신 패치노트, 직업별 공략 등의 텍스트 문서를 임베딩(Embedding)하여 벡터 DB(Vector DB)에 저장해 둡니다.
- 유저가 질문하면 LLM이 답변을 지어내지 않고, 벡터 DB에서 관련된 최신 문서를 검색(Retrieve)하여 그 내용을 바탕으로 신뢰할 수 있는 답변을 생성합니다.

## 4. 스트리밍 응답 기반의 뛰어난 UX
- AI가 답변을 모두 생성할 때까지 유저가 기다리지 않도록, 한 글자씩 실시간으로 타이핑되는 형태(SSE, Server-Sent Events)의 스트리밍 UI를 제공합니다.

## 5. 지속 가능한 마이크로서비스(MSA) 지향 구조
- 무거운 AI 연산(FastAPI)과 일반적인 회원가입/로그인/DB 세션 관리(Django)를 물리적으로/논리적으로 분리하여, 향후 사용자가 늘어나더라도 특정 모듈만 스케일 아웃(Scale-out)할 수 있는 인프라를 갖춥니다.
